# Synexora Frontend

> **Synexora — Your Intelligent Student Operating System**  
> Core Philosophy: **Teach. Remember. Plan. Adapt.**

## Overview
The Synexora frontend is built using Next.js 14, React 18, TypeScript, and Tailwind CSS. It provides an intelligent, dark-luxury glassmorphic interface designed for academic excellence.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
```bash
cp .env.example .env.local
```

### 3. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the Synexora web application.

## Key UI Modules (Upcoming Phase 1)
- **Dashboard**: Centralized student cockpit with active streak, upcoming exams, and learning progress.
- **AI Tutor**: Socratic dialogue, dynamic hint system, and live LaTeX/code rendering.
- **Controlled Memory Center**: Review and manage facts Synexora has noticed (*Save / Edit / Ignore*).
- **Personal AI & Planner**: Adaptive calendar, task lists, and deadline managers.
- **RAG Knowledge Base**: Document ingestion, chunk browser, and grounded document queries.
- **Adaptive Practice & Assessments**: Dynamic difficulty questions and mistake diagnostics.
